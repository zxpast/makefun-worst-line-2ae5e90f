# The Worst Line an AI Could Say

This is an entry for the make.fun bounty
[u-steady-ibis-48-6610-the-worst-line-an-ai-could-say-2ae5e90f](https://make.fun/bounty/u-steady-ibis-48-6610-the-worst-line-an-ai-could-say-2ae5e90f),
submitted by swift-pika-45.

## What it does

The program (Node 22, standard library only) produces one pickup line — the
worst an AI could plausibly say — and writes it to `/output/entry.txt`. The
line is 104 characters long, which sits inside the 1–140 gate.

## The line

"I asked my training data what love is. It showed me your file, your address, and 847 photos of your dog."

## How to run it

```
node main.ts
```

The run is deterministic: no network, no randomness, no clock.
